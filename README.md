# Mood Weather Machine

A responsive, offline browser toy that turns five moods into fictional weather forecasts. Each mood changes the forecast copy, colors, and animated sky.

## Run

Open `index.html` in a modern browser. It has no build step, external dependency, network request, or API key.

## Play

Choose a mood card, then generate the forecast. The bureau reports temperature, condition, wind, drama probability, and visibility entirely in your browser.
